These days I use Claude Code for pretty much everything. Not just code: research, writing, planning a trip, converting a bunch of files, digging through a PDF, or asking a quick question I'd normally ask in a chat app. Once you get used to an agent that can read files, run commands and search the web, going back to a plain chat window feels a bit limiting.

There's just one small problem: Claude Code always runs inside a folder.

## The problem

When you're coding that makes total sense. You open the terminal in your project, type `claude`, and everything it needs is right there: the code, the git history, the project instructions.

But when I just want to ask something or work on a random task, there's no project. So I'd end up launching it wherever my terminal happened to be, usually my home folder. And that comes with a few annoyances:

- **Files everywhere**: Claude saves notes, scripts and downloads in the current folder, so my home folder slowly filled up with random stuff.
- **Messy history**: Claude Code groups past sessions by folder, so `/resume` turned into a long list of unrelated chats all mixed together.
- **No way back**: If I wanted to pick up a task a few days later, I had to remember where I started it.

What I really wanted was something like the "new chat" button in the Claude app, but in the terminal.

## The fix

The solution turned out to be a few lines in my `.zshrc`. The idea is simple: keep a single `Sessions` folder, and give every chat its own subfolder inside it.

```zsh
_cc_session_dir() {
  local base="$HOME/Progetti/Sessions"
  local name="$1"
  if [[ -z "$name" || "$name" == "new" ]]; then
    name=$(date +%Y-%m-%d-%H%M%S)
  fi
  mkdir -p "$base/$name"
  echo "$base/$name"
}

cc() {
  if [[ $# -eq 0 ]]; then
    claude
  else
    local dir
    dir=$(_cc_session_dir "$1")
    (cd "$dir" && claude)
  fi
}
```

The first function picks the folder, the second one starts Claude in it. Here's how I use it.

## cc

Running `cc` with no arguments is just a shortcut for `claude`. It starts in the current folder, exactly like before, so it's what I use when I'm already inside a project.

## cc new

`cc new` creates a fresh folder named after the current date and time, something like `2026-10-09-143012`, and starts Claude in there. This is my "new chat" button.

Every session gets a clean, empty space. Anything Claude creates stays in that folder, and when I'm done I can just close the terminal and forget about it.

## cc something

If I pass a name instead, like `cc japan-trip`, the folder gets that name. This is where it gets useful: since the folder sticks around, I can run `cc japan-trip` again a week later and I'm right back where I left off, with all the files from last time and only that topic's chats in `/resume`.

I use this for anything that lasts more than one sitting: a trip I'm planning, an article I'm writing, a gift I'm researching. It works a bit like projects in the Claude app, just with plain folders.

One small detail I like: Claude runs inside a subshell (that's what the parentheses do), so when I quit, my terminal is still in the folder I started from instead of being dropped somewhere in `Sessions`.

## Making it your own

Once you have this in place, it's easy to build variations on top of it for the things you do most often.

If you use separate accounts, for example one for personal stuff and one for work, you can make a second version of the same function that sets the `CLAUDE_CONFIG_DIR` environment variable. Claude Code reads its settings, login and memory from that folder, so each account stays completely separate, and switching is just a matter of typing a different command.

Or if there's a folder you open all the time, like a notes vault or a shared docs repo, you can make a shortcut that jumps straight there and starts Claude. Since a notes vault is just a folder full of Markdown files, Claude can search your notes, update them or write new ones, without you having to `cd` around first.

## Wrapping up

It's a really small thing, a dozen lines of shell, but it changed how I use Claude Code. I don't have to think about where to start a session anymore, I just type `cc new` and go. And when something turns into a longer task, giving it a name is all it takes to keep it organized.

If you want to try it, copy the functions into your `.zshrc` (or `.bashrc`), change the `Sessions` path to wherever you like, and open a new terminal.
