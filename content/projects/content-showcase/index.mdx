The project body is the same renderer as a writing's, so a case study is built from exactly
the same blocks. Only the header above it differs: a client and a year instead of a date,
and a call to action pointing at the live site.

## The brief

A section title, then the copy it introduces. Paragraphs are justified and hyphenated, and
inline styling behaves the same here: **bold**, _italic_, and a
[link to the live site](https://example.com).

What the work had to do:

1. Give every city its own identity without redrawing the whole system.
2. Keep the palette switchable at runtime.
3. Survive a phone screen.

## Notes

Vector art skips the image optimizer entirely: an SVG imported as a URL renders as a plain
image, framed like everything else.

<Image src={mascot} alt="The project mascot, drawn as vector art" caption="An SVG, imported as a URL" />

Things that did not make the cut:

- A second navigation model, dropped after the first round.
- Per-city typography, which turned out to be one variable too many.
- A dark theme, still on the list.

That is the whole set of blocks. Anything an entry needs beyond this is a component it
brings itself.
